# Coarse-graining nonequilibrium diffusions with Markov chains

This code supports the results in the preprint: https://arxiv.org/abs/2511.05366

Numerical results are available in 'notebook.ipynb', an interactive jupyter notebook that relies on implementation of the schemes in helpers.py

Analysis of schooling fish data is in 'schooling_fish_analysis.ipynb', which is also a notebook and uses data in the 'fish_velocities' directory.

Convergence of the EPR with step-size and trajectory length are in the Python script 'inference_simulations.py'
